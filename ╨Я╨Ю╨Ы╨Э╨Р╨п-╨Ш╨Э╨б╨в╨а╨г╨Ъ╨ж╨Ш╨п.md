# Apix Desktop 0.11.3

Экспериментальное приложение Windows x64, .NET 8. Окно 0.11.3 оформлено по присланному образцу: боковая навигация переключает отдельные страницы обзора, аккаунтов, профилей, хоткея, действий и журнала. Сохранён доступный для выделения журнал с кнопкой копирования. Выбор окна и панель параметров не отображаются, оставлена настройка хоткея; целевой интервал нажатий фиксирован на **5 мс**. Сборка WPF проверена кросс-компиляцией, но интерфейс и Win32-ввод этой версии не запускались разработчиком в Windows/WoW.

## Иконка в Windows

Используется исходное изображение пользователя: иконка встроена в EXE и в ресурсы окна, а логотип встроен в интерфейс. В отдельном `Apix.ico` есть форматы 16–256 пикселей для ярлыка. Если Проводник или закреплённый значок показывает прежнюю иконку, распакуйте программу в новую папку, запустите новый `Apix.exe`, открепите старый значок и закрепите новую программу. Windows может кэшировать иконки. Новый внешний вид в Windows в этой среде не проверен.

## Запуск и управление

Распакуйте готовый архив целиком и запустите `Apix.exe`. В архиве также есть `Apix.ico` — его можно вручную назначить ярлыку через «Свойства → Сменить значок». Требуется .NET 8 Desktop Runtime x64. Для сборки в VS Code откройте папку `Apix/Desktop`, установите .NET 8 SDK и расширение C#, затем:

```powershell
dotnet restore .\Apix.App\Apix.App.csproj
dotnet build .\Apix.App\Apix.App.csproj
dotnet run --project .\Apix.Core.Tests\Apix.Core.Tests.csproj
dotnet run --project .\Apix.App\Apix.App.csproj
```

Для статической проверки структуры интерфейса дополнительно можно выполнить `python .\tests\test_ui_structure.py`; она не запускает WPF и не проверяет работу переключения страниц или буфера обмена Windows. Баннер — встроенная иллюстрация; Windows/WPF визуально в этой среде не проверены.

Слева находятся кнопки переключения отдельных страниц. Обзор показывает реальные состояние, число профилей и действий и последние события; декоративных счётчиков нет. На странице «Профили» показываются сохранённые профили и находится установка аддона; список предназначен для просмотра, профиль выбирается автоматически по identity. Настройки хоткея, таблица действий и копируемый журнал находятся на своих страницах. Индикатор подключения показывает результат автоматического поиска окна, а не проверку блоков или аддона. Если игра не найдена, проверьте, что клиент запущен, и посмотрите журнал. Если при запуске найдено несколько возможных окон WoW и ни одно ранее не выбрано автоматически, программа не угадывает: оставьте одно окно игры. Ручной выбор окна и диагностика окон в этой версии убраны из интерфейса.

**«Тест без ввода»** — отдельная кнопка: она вооружает программу в тестовом режиме без отправки клавиш. **«Запустить»** вооружает программу для реального ввода без дополнительного подтверждения. «Пауза» или Ctrl+F12 останавливает ввод. После теста повторный пуск хоткеем продолжит тестовый режим; для реального ввода нажмите «Запустить». Если за текущий сеанс тест ещё не запускался, хоткей запускает реальный ввод. После перезапуска программа всегда остановлена. Сначала проверяйте профиль, игру и рекомендации кнопкой теста.

## Экспериментальный автовход в WoW

На странице **«Аккаунты»** создайте профиль: название, логин, пароль, название мира и файл клиента `.exe`. Если открыт ровно один клиент или ранее найдена одна подходящая папка, файл может подставиться автоматически; иначе нажмите «Обзор…». Нажмите «Сохранить профиль». Сохранение не требует обученных экранов; если оно не удалось, причина теперь отображается непосредственно под кнопкой. Кнопка «＋ Профиль входа» доступна и на главной странице. Аккаунты входа не заменяют профили действий.

Перед первым автовходом необходимо обучить два экрана. Делать и присылать скриншоты не требуется: Apix сам показывает локальный кадр для обучения. После нажатия каждой кнопки обучения **за пять секунд переключитесь в WoW**, убрав курсор с нужных надписей. Появится снимок клиента в окне Apix; клики делаются по снимку и не отправляются в игру.

1. На экране входа нажмите «1 Обучить экран входа». На снимке последовательно укажите центр поля логина, поля пароля и кнопки «Вход». Не вводите пароль для снимка.
2. Войдите вручную и откройте список миров. Прокрутите так, чтобы полностью было видно название нужного мира. В Apix нажмите «2 Обучить выбор мира», за пять секунд вернитесь в WoW. На снимке нажмите центр заголовка «Выбор мира», затем верхний левый и нижний правый угол прямоугольника вокруг **всего названия одного мира**, включая `[Proxy RU]` или другой суффикс, и затем центр кнопки «ОК». Не выделяйте соседние строки. На сохранение идут только небольшие образцы кнопки, заголовка и названия; полный снимок не записывается.
3. Выберите профиль и нажмите **«Запустить WoW»** на странице аккаунтов или обзоре. Если WoW не запущен, откроется выбранный `.exe`. Если открыт один клиент, программа проверит, что он запущен из того же `.exe`, и будет ждать в нём экран входа; при нескольких окнах она не выбирает наугад. Для уже открытого клиента перейдите к экрану входа и верните фокус игре. Не используйте клавиатуру и мышь во время ввода. Программа проверит обученный экран, попытается ввести данные, распознать окно выбора и найти сохранённое название, прокручивая список, затем нажмёт «ОК». Кликер при этом не запускается. Сообщение об отправке команды выбора не подтверждает фактический вход на нужный мир: проверьте экран персонажей.

При изменении размера клиентской области приложение экспериментально ищет сохранённый образец с несколькими вариантами масштаба рядом с ожидаемым центром и переносит координаты относительно найденного образца. Это не универсальное распознавание: изменение шрифта, UI scale, цвета, DPI, компоновки, соотношения сторон или метода рендеринга может помешать поиску либо изменить положение полей. При отсутствии или неоднозначности совпадения в области поиска ввод не выполняется; если клиент иначе располагает поля, переобучите его и проверьте под наблюдением. GDI может не захватывать игру или возвращать устаревший кадр. Название мира ищется как изображение, а не как проверенная сервером строка; изменение цвета имени или неуникальный образец может помешать поиску. При неожиданном результате прекратите использование.

Обучение экрана входа может использоваться другими профилями с тем же путём к .exe, а образец мира — профилями с тем же .exe и названием мира. Если сохранённые варианты не совпадают, программа не выбирает их наугад. Для нового, ранее не обученного мира всё ещё нужно отдельное обучение: распознавание названия по введённому тексту не реализовано. Полный кадр не записывается в профиль и никуда не отправляется.

Если после входа уже открыт последний мир, автоматически открыть список эта версия не умеет; при появлении кода, ошибки или CAPTCHA завершите шаг вручную и откройте окно миров до окончания ожидания. Код/защита не обходятся. Изменение фокуса или удерживаемые модификаторы во время ввода прерывают попытку. **Ctrl+F12** отменяет автовход и кликер, если хоткей успешно зарегистрирован; на странице аккаунтов есть кнопка отмены. Проверка фокуса и отправка системных нажатий не атомарны, поэтому абсолютная защита от ввода в неверное окно или поле невозможна. Не работайте в других окнах во время ввода.

Логин и пароль сохраняются локально в файле `%LOCALAPPDATA%\Apix\Accounts` в виде данных, зашифрованных Windows DPAPI для текущей учётной записи Windows. Они не добавляются в журнал, аргументы запуска и буфер обмена. Название профиля, мира, путь к клиенту, координаты и небольшие образцы экрана хранятся открыто. DPAPI не защищает от вредоносной программы, запущенной под тем же пользователем; во время работы расшифрованные данные находятся в памяти процесса. Перенос файла другому пользователю или на другой компьютер обычно не позволит их расшифровать. Никому не отправляйте файлы профилей и пароль.

**Ограничения текущей версии:** автоматическое переподключение после разрыва и выбор последнего персонажа ещё не реализованы. Автовход не начинает работу самостоятельно после разрыва. Экспериментальное масштабирование проверено только на синтетических кадрах; оно не гарантирует работу при любом размере окна и любой настройке интерфейса.

Сборка и тесты сопоставления шаблонов проведены вне Windows; реальный DPAPI, захват WoW, Unicode-ввод и последовательность входа в клиенте **не проверены**. Сначала проверяйте работу под наблюдением; для отключения автовхода удалите профиль на странице аккаунтов.

## Установка аддона в игру

Откройте страницу «Профили» и нажмите **«Установить аддон»**. Если открыта одна папка WoW, путь берётся из исполняемого файла найденного процесса. При первом запуске без игры, нескольких разных папках или недоступном пути появится выбор папки. Можно также нажать **«Выбрать папку…»** и выбрать корневую папку игры или вложенную папку `Interface`, `AddOns` либо `AddOns/Apix`: программа определит корень автоматически. Поддерживаются и переименованные EXE, если структура похожа на WoW: `Data` и `Interface` или `WTF`, либо `Interface/AddOns` и `WTF`. Иначе нужен стандартный файл `Wow.exe`, `Wow-64.exe`, `WowB.exe` или `Wow-64B.exe` в корне. Структура папок не доказывает версию клиента.

После первой установки путь сохраняется в `%LOCALAPPDATA%\Apix\game-folder.txt` и может использоваться, когда WoW закрыт. Диски и реестр программа не сканирует. При нескольких открытых клиентах с разными папками она не угадывает.

В приложение встроен Apix 0.6.6. Установщик проверяет комплект и копирует только 11 файлов в `<WoW>\Interface\AddOns\Apix`, сохраняя неизвестные файлы внутри этой папки. `WTF`, другие аддоны и сохранённые персонажи не изменяются. При ошибке он пытается восстановить заменённые файлы; если это не удалось, путь к резервным копиям указан в сообщении и журнале. При недостатке прав проверьте доступ к папке игры. Символьные ссылки и точки повторной обработки внутри пути `Interface\AddOns\Apix` отклоняются.

**Полностью закройте и снова запустите WoW после установки**, а не только `/reload`. Установка останавливает ввод. До закрытия открытых окон WoW эта сессия программы блокирует запуск кликера; эта проверка не переживает перезапуск самой программы. Программа проверяет файл или структуру папок, но не определяет точную версию игры: выберите именно клиент Legion 7.3.5. Hekili отдельно не устанавливается. После обновления с ручного выбора дисплея введите `/apix display auto`. Экспорт профилей при необходимости импортируйте как раньше.

Сборка и тесты ядра выполнены вне Windows; автоматическое определение процесса, выбор папки, запись под Windows и реальный запуск WoW ещё требуют проверки на вашей системе.

## Копирование журнала

Откройте раздел «Журнал» слева. Выделите нужные строки мышью и нажмите Ctrl+C (Ctrl+A — выделить весь текст) либо нажмите **«Копировать всё»**, чтобы скопировать журнал целиком. В журнале хранятся последние примерно 70 строк за текущий сеанс; полный архив событий не создаётся. В отчёте могут быть имена персонажей, миры, PID и названия окон — проверьте перед отправкой. При переходе в окно Apix игра теряет фокус и реальный ввод приостанавливается до возврата фокуса.

## 5 мс и совместимость профилей

В 0.8 интервал не редактируется и всегда равен 5 мс, независимо от значения, сохранённого в старом профиле. Это целевой **минимальный** интервал между отправками, не гарантия: Windows, планировщик WPF, захват и игра могут работать медленнее. Пропущенные тики не отправляются пачкой; журнал периодически показывает приблизительный фактический интервал при непрерывной серии. Программный GCD, антиповтор и индивидуальные задержки не применяются; игровой GCD не меняется.

Старые профили и хоткей читаются автоматически из `%LOCALAPPDATA%\Apix`, настройки действий остаются. Профиль, сохранённый версией 0.7 или 0.8, содержит интервал 5 мс; старые версии Desktop с ограничением от 10 мс могут его не открыть. Перед откатом сохраните резервную копию папки профилей или используйте ранее экспортированный файл.

Настройки цвета, области и прежний режим поиска/ручные координаты из старого профиля сохраняются внутри него, но больше не доступны для редактирования в интерфейсе. Новые импорты по умолчанию используют автопоиск блоков. Если GDI не захватывает кадр или профиль ранее был в ручном режиме с неправильными координатами, эта версия не предоставляет ручной калибровки на экране; можно временно использовать предыдущую версию с резервной копией профиля.

## Профили и действия

**При повторном запуске повторно импортировать уже сохранённый профиль не требуется.** Программа загружает библиотеку при открытии. Если активный персонаж ещё не определён, после нажатия «Запустить» или «Тест без ввода» она ждёт фокуса WoW и ищет однозначное совпадение identity и блоков; до успешной проверки ввод не отправляется. Даже если в библиотеке несколько профилей, первый или последний не выбирается наугад; при нескольких подходящих профилях выберите нужный вручную. Найденный профиль восстанавливает сохранённые параметры; при изменении области/допуска поиск повторяется. Игра должна быть запущена, а её блоки видимы и доступны захвату GDI. Программа сама не запускается при открытии.

Если журнал пишет «Нет сохранённых профилей», импортируйте экспорт один раз и проверьте сообщение об успешном сохранении. Путь библиотеки выводится в журнал и обычно находится в `%LOCALAPPDATA%\Apix\Profiles`. Ошибки доступа или повреждённых файлов выводятся отдельно и блокируют запуск; файлы не удаляются автоматически. При запуске от другого пользователя Windows библиотека может быть другой.

Для каждого персонажа и специализации один раз выполните в WoW `/apix export`, скопируйте строку и нажмите «Импорт из буфера». Все строки нового импорта включены: проверьте действие, цвет, клавишу и источник. Таблица позволяет включить или отключить строку; цвет и клавишу можно изменить двойным щелчком. Приоритет сохраняется, но не разрешает неоднозначность цветов. Для ручной выгрузки/открытия файла есть кнопки «Сохранить» и «Открыть».

При активном WoW программа пытается выбрать заранее импортированный профиль по identity и расположению пикселей. Файлы лежат локально в `%LOCALAPPDATA%\Apix\Profiles` и содержат имя персонажа и мир. Если на текущем кадре подходят несколько профилей, автоматический выбор не угадывает между ними. Откройте «Профили», нажмите «Выбрать» у нужного персонажа, затем «Запустить» или «Тест без ввода». Выбор закреплён на текущий сеанс; «Автовыбор» возвращает автоматический режим. Импорт и открытие файла также фиксируют этот профиль вручную. Разные профили могут иметь одинаковые или близкие цвета identity: само по себе это больше не запрещает запуск. **Если цвета совпадают с учётом допуска, программа не отличит персонажей и может отправить клавиши выбранного профиля не тому персонажу. Перед запуском и после смены персонажа проверяйте выбор самостоятельно.** Ошибки библиотеки и неизвестные сигналы по-прежнему блокируют ввод. Неизвестный профиль в активном режиме ищется до 15 секунд, затем ввод останавливается. Один цвет не гарантирует уникальной идентификации.

## Хоткей и фокус

В разделе «Горячая клавиша» введите, например, `~`, `Ё`, `F8` или `CTRL-F11`, нажмите «Назначить» и проверьте надпись о регистрации. `~` и `Ё` обозначают клавишу под Escape без Shift; для сочетания с Shift введите `SHIFT-~`. Хоткей глобальный и обычно перехватывается Windows во всех приложениях; выбирайте свободную клавишу. Основная клавиша хоткея не должна совпадать с включённым действием даже с другими модификаторами. F12 зарезервирована для аварийного Ctrl+F12. Кнопка «Снять» освобождает хоткей. Настройка хранится в `%LOCALAPPDATA%\Apix\settings.json`.

При потере фокуса или сворачивании WoW вооружённый кликер приостанавливает ввод. При возврате фокуса к выбранному окну он повторно проверяет сигнал и при автопоиске расположение блоков, после чего может продолжить. Закрытие окна, смена PID, серьёзная ошибка ввода или неоднозначный сигнал приводят к остановке. Ручная пауза не снимается возвратом фокуса: нажмите хоткей или кнопку запуска. Между проверкой foreground и `SendInput` остаётся возможная гонка.

## Защита чата

Для защиты поля ввода нужен аддон Apix 0.6.5 или новее. Кнопка установки ставит встроенную версию 0.6.6; после этого полностью перезапустите WoW. Программа сама не определяет, какая версия уже загружена в клиент: с 0.6.4 защита чата не работает.

Аддон делает блок рекомендации чёрным при обнаруженном активном поле текста; кликер не отправляет действия на чёрном сигнале. После закрытия поля текущая рекомендация может возобновиться. Чёрный также означает отсутствие рекомендации; по одному сигналу программа не различает эти причины. Поле может обнаруживаться через `GetCurrentKeyBoardFocus`, чатовые API или запасные методы. При недоступных или ошибочных методах аддон оставляет блок чёрным; нестандартные сторонние поля и устаревший кадр могут не распознаваться.

Перед реальным вводом введите `/apix test on`, откройте чат: красный блок должен стать чёрным, после Esc снова красным. Затем `/apix test off` и проверьте кнопку «Тест без ввода». Рендер и внешнее чтение пикселей не синхронизированы; защита не гарантирует, что ни одна клавиша не попадёт в чат. Для надёжного набора сначала вручную приостановите кликер.

## Ограничения

Физический и программный ввод используют общее состояние клавиатуры. При удержании Shift/Ctrl/Alt автоматическая клавиша может стать комбинацией с этим модификатором; нажатие той же физической клавиши может нарушить её удержание. Кнопки мыши отправляются только при указателе над клиентом WoW; при выходе указателя отправка мыши ожидает возврата. GDI может не видеть DirectX-кадр или считывать устаревшие цвета. Приложение не подтверждает, что игра приняла способность. Реальный ввод в этой среде не тестировался; проверьте правила сервера перед использованием.
